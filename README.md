# PicPac

Мобильное приложение (Expo 58, React Native, TypeScript): загрузка фото, макет печати, фотокниги, постера или открытки, оформление заказа. Интерфейс на русском, цены в BYN.

## Запуск

Нужен [Node.js](https://nodejs.org/) (LTS). Дальше из корня проекта (где лежит `package.json`):

```bash
npm i
npx expo start
```

Появится Metro и QR-код в терминале (иногда ещё откроется страница в браузере с тем же QR).

### Телефон: Expo Go

1. Поставь **Expo Go** ([iOS](https://apps.apple.com/app/expo-go/id982107779) / [Android](https://play.google.com/store/apps/details?id=host.exp.exponent)).
2. В Expo Go войди в аккаунт [expo.dev](https://expo.dev) (Sign in).
3. В терминале на компе — **тот же аккаунт**, иначе QR и туннель часто не сходятся:

   ```bash
   npx expo login
   ```

4. Отсканируй QR из терминала камерой (iOS) или из Expo Go (Android). Телефон и комп должны быть в одной Wi‑Fi-сети; если нет — в меню dev server выбери **Tunnel** и отсканируй снова.

### Браузер

В том же терминале, где крутится `expo start`, нажми **`w`** — откроется веб-версия. Или сразу:

```bash
npx expo start --web
```

Галерея и камера в браузере ограничены; для полного сценария удобнее Expo Go.

### Если нужен свой билд (AR, не Go)

```bash
npm run ios
npm run android
```

Нужны Xcode / Android Studio. Или сборка в облаке через EAS — отдельная настройка.

### Прочее

```bash
npx tsc --noEmit
npm run lint
npx expo install <пакет>   # новые зависимости Expo, не голый npm install
```

Демо без реальной обработки фото: `.env.example` → `.env`, `EXPO_PUBLIC_USE_AI_MOCKS=true`, перезапустить `npx expo start`.

## Редактор фото

Открывается из макета: выберите ячейку с фото → «Редактировать». Та же модалка доступна из лотка и панели AI-студии. Правки одного снимка видны везде, где он используется.

### Базовые действия

| Действие | Что делает |
| --- | --- |
| **Повернуть** | Поворот на 90° с анимацией. Рамка обрезки подстраивается под новую ориентацию. |
| **Обрезать** | Режим кадрирования: двигаете рамку, тянете красный маркер или щипком меняете размер. Пропорции рамки = пропорции ячейки в макете (печать, слот книги и т.д.). «Обрезать» применяет только кадр; «Отмена» выходит без изменений. |
| **ОК** | Сохраняет поворот, обрезку и все эффекты в файл и подставляет фото в макет. Закрытие крестиком или без «ОК» — макет не меняется. |

Перед открытием тяжёлые оригиналы приводятся к рабочему размеру (~2048 px по длинной стороне), чтобы редактор не падал по памяти. Исходник и параметры кадра хранятся отдельно: повторное открытие позволяет сдвинуть обрезку, пока вы не нажали «ОК» с финальным кропом.

### Умные инструменты (панель под кнопками)

Всё считается **на телефоне**, без отправки на сервер.

**Инструменты:**

- **Автоулучшение** — вытягивает яркость по гистограмме, слегка добавляет резкость.
- **Подобрать кадр** — предлагает рамку по контрасту/деталям с сохранением пропорций ячейки; можно поправить руками.
- **Резкость** — отдельное усиление резкости.
- **Однотонный фон** — вырезание простого фона по краям (PNG с альфой; на сложном фоне часто бессмысленно).

**Фильтры и стили** (раскрывающийся блок): ч/б, сепия, контраст, светлее, мягкость, ретро, прохлада.

**Служебное:**

- Блок **качества** — замечания по снимку и ориентир макс. размера при 240 dpi (грубо, не ML).
- **Обрабатывать уменьшенную копию** — для фото &gt; 8 Мп: эффекты на копии до 2000 px, чтобы не упереться в память.
- **Отменить обработку** — до 3 шагов назад по цепочке эффектов.
- **Вернуть оригинал** — сброс к загруженному файлу в редакторе.

Фильтры меняют рабочий bitmap; область вне рамки остаётся в файле до финального «ОК» с обрезкой.

### Проверка качества до редактора

После загрузки в фоне гоняется лёгкий анализ (разрешение, яркость, контраст, пересвет, резкость). Предупреждения на экране выбора продукта и в макете; в тексте указываются **номера фото** в том же порядке, что миниатюры (например, «фото 2, 5»).

## Остальное в приложении

**Продукты:** фотопечать (форматы, поля, рамки, копии), фотокнига (развороты, обложка, сетки, перелистывание), постер (AR-примерка на поддерживаемых сборках), открытка (3D-стороны, текст).

**Макет:** лоток, перетаскивание в ячейки, автопорядок по дате и GPS из EXIF, умный автомакет книги, черновики, расчёт цены, checkout с заглушкой заказа.

**Навигация:** Expo Router, экраны в `src/screens/`, состояние в `usePicPacController`.

## Бекенд и админка

```text
server/   API на Node.js + Fastify, база SQLite (встроенный node:sqlite, ничего ставить не надо)
admin/    админ-панель: React + Vite
```

Нужен Node.js 22.18+ (TypeScript запускается без сборки).

```bash
npm run setup:backend   # один раз: зависимости server/ и admin/
npm run api             # API на http://localhost:4000 (при первом запуске база заполнится демо-данными)
npm run admin           # админка в режиме разработки: http://localhost:5173/admin/
```

Пароль админки по умолчанию — `picpac-admin`. Чтобы задать свой, скопируйте `server/.env.example` в `server/.env` и поменяйте `ADMIN_PASSWORD`.

Для показа без Vite: `npm run admin:build`, и сервер сам раздаёт админку на http://localhost:4000/admin/.

**Что умеет админка:**

- **Дашборд** — выручка за 30 дней, средний чек, график выручки по дням, заказы по статусам, выручка по продуктам, промокоды.
- **Заказы** — фильтры по статусу и продукту, поиск по номеру, имени и телефону. В карточке: смена статуса с комментарием, отмена, фото из заказа (можно скачать), история изменений, заметка менеджера.
- **Каталог и цены** — форматы печати, линейки фотокниг, размеры постеров, доставка, цены разворота и открытки. Можно менять, скрывать и добавлять позиции; приложение подхватит их при следующем запуске.
- **Промокоды** — скидка в %, лимит использований, срок действия, включение и отключение.
- **Пакет к печати** — кнопка «Скачать к печати» в карточке заказа. В ZIP лежат фото в порядке макета (`photos/01_Обложка.jpg`, `02_Разворот_1_ячейка_1.jpg`…), «Паспорт заказа.txt» с параметрами печати, обложки, сетками разворотов и доставкой, «Состав.csv» (файл → ячейка, формат, копии, поля и рамка; открывается в Excel) и `order.json` с полной конфигурацией. Если каких-то фото не хватает, паспорт об этом предупреждает.
- **Живые обновления** — админка держит поток событий (SSE, `/api/admin/events`). Новый заказ приходит сразу: всплывает уведомление со звуком (выключается в меню слева), на пункте «Заказы» и в заголовке вкладки появляется счётчик, строка в списке подсвечивается. Дашборд, список и карточка заказа обновляются сами, когда клиент догружает фото или другой менеджер меняет статус.

**Как с API работает приложение.** При старте приложение запрашивает каталог и заказы. Адрес сервера — тот же хост, что у Metro, порт 4000; в web это `localhost:4000`, в Expo Go — IP компьютера в Wi‑Fi. Другой адрес можно задать через `EXPO_PUBLIC_API_URL=http://192.168.1.5:4000`; если Expo запущен в режиме Tunnel, адрес задать обязательно. Значение `EXPO_PUBLIC_API_URL=off` отключает сервер. Если сервер недоступен, приложение работает на локальных моках, как раньше.

При оформлении заказа сервер сам пересчитывает сумму по своему каталогу и проверяет промокод; итог, посчитанный приложением, не используется. Фото из макета загружаются в фоне после оформления. Экран заказов раз в 15 секунд подтягивает статусы, которые менеджер меняет в админке. Заказы привязаны к устройству по случайному clientId.

```bash
npm run api:test                 # тесты API
npm --prefix server run seed     # сбросить базу к демо-данным
```

Данные лежат в `server/data/` (база и загруженные фото), папка в `.gitignore`.

**Ограничения прототипа:** вход в админку по одному общему паролю, без ролей. Оплата не проводится. Фото доступны по случайной ссылке без отдельной авторизации. Наружу сервер стоит выставлять только за HTTPS и со сменённым паролем.

## Чего нет (прототип)

Заказ не уходит в типографию, оплата — заглушка. Облачный AI, super-resolution и ретушь не подключены. AR постера — нативный модуль (`@stewmore/expo-ar`) в dev build; в Expo Go — упрощённая примерка на камере.

Черновики и идентификатор устройства для заказов хранятся через `@react-native-async-storage/async-storage` (`src/services/storage.ts`).

Юнит-тесты обработки: `npm run test:smart-tools`.
