# PicPac

Мобильное приложение (Expo 58, React Native, TypeScript): загрузка фото, макет печати, фотокниги, постера или открытки, оформление заказа. Интерфейс на русском, цены в BYN.

## Запуск

Нужен [Node.js](https://nodejs.org/) (LTS). Дальше из корня проекта (где лежит `package.json`):

```bash
npm i
npx expo start
```

Появится Metro и QR-код в терминале (иногда ещё откроется страница в браузере с тем же QR).

### Телефон: Expo Go

1. Поставь **Expo Go** ([iOS](https://apps.apple.com/app/expo-go/id982107779) / [Android](https://play.google.com/store/apps/details?id=host.exp.exponent)).
2. В Expo Go войди в аккаунт [expo.dev](https://expo.dev) (Sign in).
3. В терминале на компе — **тот же аккаунт**, иначе QR и туннель часто не сходятся:

   ```bash
   npx expo login
   ```

4. Отсканируй QR из терминала камерой (iOS) или из Expo Go (Android). Телефон и комп должны быть в одной Wi‑Fi-сети; если нет — в меню dev server выбери **Tunnel** и отсканируй снова.

### Браузер

В том же терминале, где крутится `expo start`, нажми **`w`** — откроется веб-версия. Или сразу:

```bash
npx expo start --web
```

Галерея и камера в браузере ограничены; для полного сценария удобнее Expo Go.

### Если нужен свой билд (AR, не Go)

```bash
npm run ios
npm run android
```

Нужны Xcode / Android Studio. Или сборка в облаке через EAS — отдельная настройка.

### Прочее

```bash
npx tsc --noEmit
npm run lint
npx expo install <пакет>   # новые зависимости Expo, не голый npm install
```

Демо без реальной обработки фото: `.env.example` → `.env`, `EXPO_PUBLIC_USE_AI_MOCKS=true`, перезапустить `npx expo start`.

## Редактор фото

Открывается из макета: выберите ячейку с фото → «Редактировать». Та же модалка доступна из лотка и панели AI-студии. Правки одного снимка видны везде, где он используется.

### Базовые действия

| Действие | Что делает |
| --- | --- |
| **Повернуть** | Поворот на 90° с анимацией. Рамка обрезки подстраивается под новую ориентацию. |
| **Обрезать** | Режим кадрирования: двигаете рамку, тянете красный маркер или щипком меняете размер. Пропорции рамки = пропорции ячейки в макете (печать, слот книги и т.д.). «Обрезать» применяет только кадр; «Отмена» выходит без изменений. |
| **Готово** | Сохраняет поворот, обрезку и эффекты в макет. В режиме кадра сначала подтверждает рамку; крестик закрывает редактор без сохранения. |

Для предпросмотра используется копия до 2048 px. «Готово» сразу сохраняет эффекты, поворот и обрезку в исходном разрешении, показывая прогресс. Снимки больше 8 Мп обрабатываются полосами с перекрытием, общей экспозицией и потоковой записью PNG (`fflate`), без полного RGBA-буфера в JavaScript. Перекрытие исключает швы размытия и резкости. Маска однотонного фона рассчитывается на копии до 2048 px и переносится на исходное разрешение. Дополнительного подтверждения и уменьшения размера при сохранении нет. Исходник, рецепт эффектов и параметры кадра хранятся отдельно: при повторном открытии можно менять область и выключать сохранённые эффекты.

### Умные инструменты (панель под кнопками)

Всё считается **на телефоне**, без отправки на сервер.

**Инструменты:**

- **Авто** — адаптивная экспозиция, диапазон яркости по гистограмме, насыщенность и мягкая резкость.
- **Подобрать кадр** — предлагает рамку по контрасту/деталям с сохранением пропорций ячейки; можно поправить руками.
- **Резкость** — отдельное усиление резкости.
- **Однотонный фон** — вырезание простого фона по краям (PNG с альфой; на сложном фоне часто бессмысленно).

Вкладки **Коррекция** и **Фильтры**: ч/б, сепия, контраст, светлее, размытие, ретро и прохладные тона. Резкость — пороговая нерезкая маска; размытие учитывает прозрачность и размер изображения.

**Служебное:**

- **Стрелки назад / вперёд** — до 12 сохранённых предыдущих состояний, включая эффекты, поворот, рамку и сброс. После новой правки ветка повтора очищается.
- **Исходник** — удержание показывает исходное фото без изменения результата; подпись и размер кнопки постоянны.
- При включении/выключении эффектов и переходах по истории предыдущая фотография остаётся на экране до загрузки следующей, затем плавно сменяется новой. Для сравнения исходник заранее отображается в отдельном скрытом слое.
- **Сброс** — возврат к загруженному файлу; его тоже можно отменить стрелкой.
- Активные эффекты выделены цветом и галочкой. Повторное нажатие убирает только выбранный эффект: остальные пересчитываются от исходника. Результаты рецептов кешируются; обработка не накапливается поверх себя.
- Уведомлений об успешном применении и сохранении нет. Ошибка показывается внутри редактора и сохраняет предыдущий результат.
- Во время обработки и сохранения по фотографии проходит мягкий световой блик с тёплым и мятным переливом вместо спиннера. Слой плавно исчезает после обработки; анимация не задерживает результат, останавливается в простое и учитывает системное уменьшение движения.

Фильтры меняют полный рабочий bitmap; область вне рамки остаётся доступной при повторном редактировании. PNG сохраняет прозрачность. Чтение поддерживает палитровые и 16-битные PNG; на вебе результат хранится в Blob, на телефоне — в локальном файле.

### Проверка качества до редактора

После загрузки в фоне гоняется лёгкий анализ (разрешение, яркость, контраст, пересвет, резкость). Остаётся одно короткое сообщение на этапе загрузки: «Фото 1 и 3 — низкого качества». При прямой загрузке в выбранное изделие это одно уведомление после завершения проверки. В макете, редакторе, на миниатюрах лотка и при оформлении дополнительных предупреждений нет; оформление открывается без повторного подтверждения.

Автокоррекция бережно оценивает баланс белого только по нейтральным участкам, сохраняет оттенки при изменении яркости и меньше усиливает шум в тенях. Удаление однотонного фона уменьшает светлую кайму на границе объекта. Поддержаны палитровые PNG, 1/2/4-битные монохромные изображения и 16-битные каналы. Входные пиксели рецепта кешируются до закрытия редактора; промежуточный буфер размытия использует вдвое меньше памяти, чем Float32.

### Панели и навигация

Верхняя и нижняя панели макета используют один фон: одинаковый светлый оттенок, прозрачность и блюр (42). Под верхней панелью — короткая плавная тень высотой 10 px; ступенчатых полос блюра нет. Начальный отступ контента увеличен до 80 px, чтобы он не попадал под тень. На экране макета контент прокручивается под панелями; нижний лоток и оплата объединены в компактную матовую панель. Размер и оформление отпечатка сворачиваются. Нижняя навигация «Главная / Заказы / Профиль» белая и непрозрачная. В фоторедакторе зелёной подложки под изображением нет.

Произвольные цвета названия и рамки обложки, полей и рамок фотопечати/постера выбираются через общий круговой HSV-пикер с регулировкой яркости, быстрыми белым/чёрным и предпросмотром оттенка. Цвет применяется по «Выбрать цвет»; отмена сохраняет прежний. Ручного HEX-ввода нет. Пикер работает на уже подключённых `react-native-svg` и `expo-linear-gradient`, новых нативных зависимостей нет.

### Предпросмотр фотокниги

Новые книги по умолчанию имеют формат 21×30 см; он первым предлагается для всех линеек. Ранее выбранный формат сохранённого макета сохраняется. Обложка и страницы имеют мягкое затемнение внешних краёв, светлый блик и тонкие линии среза бумаги. Один декоративный компонент используется для интерактивных страниц и снимков перелистывания, не меняя их размеры, обработку касаний или механизм анимации. Скругления страницы, снимка и анимированного затемнения берутся из общего описания поверхности: 6 px для обложки и 4 px для внешних углов листа; край у переплёта остаётся прямым.

### AR-постер

- В сборке с `@stewmore/expo-ar` используются ARKit/ARCore, поиск вертикальной стены и четыре мировых якоря по углам постера. Из проекций углов строится матрица перспективы: постер следует плоскости стены, включая поворот и перспективное сокращение, а не остаётся плоским прямоугольником экрана.
- Перетащите постер и отпустите палец, чтобы перенести его на новую точку стены. Новая привязка создаётся целиком до удаления прежней; при ошибке распознавания старая точка сохраняется. «Закрепить» защищает от случайного переноса; «Переместить» снова включает редактирование.
- Масштабирование жестом отключено в обоих режимах AR. Кнопки «−/+» меняют размер примерки с шагом 1 см по короткой стороне; долгое нажатие даёт шаг 5 см. Диапазон короткой стороны — 5–150 см (146 вариантов), пропорции выбранного постера сохраняются. На границах диапазона соответствующая кнопка недоступна; из минимального размера всегда можно увеличиться обратно. Центр привязки сохраняется, а в настоящем AR создаются новые якоря для выбранных размеров; при неудаче остаётся прежний размер. Произвольный размер примерки не меняет печатный формат и цену заказа: исходный формат печати отдельно указан в панели. Перетаскивание одним пальцем доступно в режиме «Переместить». Второй палец не меняет размер и не снимает закрепление. «В центр» сохраняет выбранный размер примерки.
- Отображаются выбранные поля и рамки, небольшая тень и лёгкое затенение поверхности. Это приближённая визуализация материала; окклюзия реальными объектами и оценка освещения комнаты не реализованы.
- В Expo Go и на мобильном вебе кнопка «Закрепить» использует **приближённую стабилизацию по относительным поворотам DeviceMotion** (`expo-sensors`). Угловые скорости переводятся из градусов/с в радианы с учётом разных обозначений осей iOS, Android и браузера. Абсолютные углы и компас не влияют на привязку. Некорректные, повторные и устаревшие измерения отбрасываются; при длительном разрыве данных привязка сбрасывается. Кватернион сглаживается с малой задержкой при движении и подавлением мелкого шума в покое. Проекция обновляется через requestAnimationFrame; неизменившееся положение не вызывает перерисовку. Постер сохраняет направление, вращение и выбранный экранный размер: при отведении камеры к краю кадра он не растягивается. В камере используется прежняя чувствительность смещения с приблизительным горизонтальным углом обзора 60°; на iOS выбрана основная широкоугольная камера без автоматической смены объективов. Такая примерка не измеряет глубину и перенос телефона: для точной фиксации на стене нужна AR-сборка с ARKit/ARCore. Возможны остаточная ошибка и накопление дрейфа.
- Проекции настоящего AR (~30 кадров/с у нативного модуля) сглаживаются по кадрам экрана с общим коэффициентом для всех четырёх углов, сохраняя перспективу и физический масштаб. При потере трекинга постер скрывается до восстановления проекций. Неполный набор углов при замене якорей допускается на короткое время без мигания; устаревшее сглаживание отменяется перед перетаскиванием и масштабированием.
- В примерке камерой наклон вычисляется по базису плоскости постера, без перспективного уклона верхней кромки: боковой поворот/наклон камеры не создаёт искусственный крен у постера, размещённого в стороне от центра. Относительное вращение интегрируется по среднему соседних показаний угловой скорости, чтобы уменьшить ошибку при изменении скорости движения.
- Перед привязкой выполняется короткая проверка нулевого смещения угловых скоростей (около 0,24 с). Вычитается только очень малый постоянный сдвиг с низким разбросом; обычное движение отключает эту коррекцию. Очень медленные повороты больше не отбрасываются порогом угловой скорости; визуальное сглаживание подавляет мелкое дрожание отдельно от интеграции.
- При нажатии «Закрепить» проверяется доступ к датчикам и при необходимости запрашивается разрешение. Если датчиков нет, доступ запрещён или показания не поступают, интерфейс сообщает об этом и не выдаёт блокировку касаний за успешную стабилизацию. После сворачивания приложения подписка снимается; после возврата нужно закрепить постер заново. При уходе постера из кадра он не прилипает к краю экрана: повернитесь обратно или нажмите «В центр». «Переместить» отключает привязку, сохраняя текущий вид; кнопки масштаба работают и при включённом удержании.
- Камера и AR-сессия монтируются только пока открыт просмотр. Для оценки стабильности настоящих якорей необходимо тестирование на устройстве с поддержкой AR в development build; экспорт JS-бандла этого не проверяет.

## Остальное в приложении

**Продукты:** фотопечать (форматы, поля, рамки, копии), фотокнига (развороты, обложка, сетки, перелистывание), постер (AR-примерка на поддерживаемых сборках), открытка (3D-стороны, текст).

**Макет:** лоток, перетаскивание в ячейки, автопорядок по дате и GPS из EXIF, умный автомакет книги, черновики, расчёт цены, checkout с заглушкой заказа.

**Навигация:** Expo Router, экраны в `src/screens/`, состояние в `usePicPacController`.

## Чего нет (прототип)

Заказ не уходит в типографию: каталог, доставка и статусы — локальные моки. Облачный AI, super-resolution и ретушь не подключены. AR постера — нативный модуль (`@stewmore/expo-ar`) в dev build; в Expo Go — упрощённая примерка на камере.

Черновики: реализация в `src/services/storage.ts`. Без `@react-native-async-storage/async-storage` данные живут до закрытия приложения.

Юнит-тесты обработки: `npm run test:smart-tools`. Геометрия стены, перспективные проекции и восстановление масштаба: `npm run test:ar`.
